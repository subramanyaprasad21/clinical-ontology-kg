# Repository conventions

Read `docs/WRITING_CONVENTIONS.md` before editing this repository. Its writing, evidence, reproducibility and preservation rules are permanent project conventions.

Classify each file before editing: current documentation, executable code, generated artifact, historical record or frozen authority. Consult `docs/README.md` for the documentation map. Preserve historical and hash-bound bytes; update current summaries separately. Change generated reports through their generators.

Keep source identifiers, versions, hashes, query IDs and measured counts exact. Separate observations from interpretation and limitations. Keep normal technical documentation free of development conversations. Maintain attribution separately in `ATTRIBUTION.md`; do not imply unaided authorship.

Before substantial commits, check current counts against machine evidence, local Markdown links, historical/frozen file hashes, accidental personal paths, and unsupported claims. Run checks appropriate to the change. Do not broaden the frozen biomedical source scope without a documented data requirement.
